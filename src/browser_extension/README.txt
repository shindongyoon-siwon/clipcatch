ClipCatch Browser 1.7.0
1. In ClipCatch, open the browser bridge panel and choose the extension folder.
2. Visit chrome://extensions (Edge: edge://extensions). Enable Developer mode
   only if permitted by your organization, then Load unpacked and choose this folder.
3. In ClipCatch create a one-time pairing code. Paste the entire code in this
   extension's popup. The code expires in 5 minutes and cannot be reused.
4. Open the exact Reddit post, play the video, and click Find current post video.
   If it is not detected yet, play it again and reopen the popup. Pick the detected
   video and explicitly choose Send to ClipCatch. Check completion in ClipCatch.
5. Only for genuinely silent originals, enable Allow silent saving.

No cookies, passwords, browser history databases, or other-site accounts are read.
Only the armed Reddit tab is observed for ten minutes. Captured URLs are kept in
browser session memory, not synced. The local pairing key is stored in local
extension storage. You can revoke it in ClipCatch.

Only observed HTTPS v.redd.it MPD, HLS or MP4 files are supported in this release.
No DRM, paywall, private-group, CAPTCHA or access-control bypass is implemented.
Playback in a browser does not guarantee direct CDN download will be permitted.
Use media that you have permission to save and reuse.

After a ClipCatch app update, prepare the extension folder again and click Reload
on its card in chrome://extensions to update this unpacked extension.
