ClipCatch v1.9.4

업데이트 자동 안내
- 화면을 처음 열거나 다른 탭에서 돌아오면 새 버전을 자동으로 확인합니다.
- 인터넷 연결이 복구됐을 때도 다시 확인합니다.
- 프로그램을 켜 둔 동안에도 주기적으로 확인해, 새 버전이 발견되면 업데이트 창을 바로 표시합니다.
- 설정에서 업데이트 확인 버튼을 찾지 않아도 변경 내용과 [업데이트 후 다시 시작] 버튼을 볼 수 있습니다.

사용 중 확인 방식
- 처음 실행할 때의 확인이 끝나면 이후 확인은 화면을 가리지 않고 진행합니다.
- 진행 중인 다운로드·변환 작업은 계속되며, 작업이 끝난 뒤 업데이트할 수 있습니다.
- 새 버전을 아직 확인하지 못한 단순 연결 오류 때문에 일반 작업을 막지 않습니다.
- 여러 탭이나 연속된 복귀 이벤트가 같은 확인을 중복 실행하지 않도록 처리합니다.

적용
- 이전 버전에서 프로그램의 [종료]를 누른 뒤 다시 실행하면 새 버전 확인이 시작됩니다.
- 업데이트 창의 [업데이트 후 다시 시작]을 누르세요.
- 업데이트 파일 검증과 저장한 영상·설정 유지 방식은 그대로 적용됩니다.
