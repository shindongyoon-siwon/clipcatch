ClipCatch v1.9.5

업데이트 확인 간격 조정
- 프로그램을 시작하거나 화면을 열고 돌아올 때 새 버전을 확인합니다.
- 프로그램을 계속 켜 둔 동안의 정기 확인은 1분에서 15분 간격으로 변경했습니다.
- 화면을 다시 사용할 때의 확인은 15분 정기 확인과 별도로 진행합니다.
- 화면을 연속해서 열거나 여러 탭을 빠르게 오가는 경우에는 최근 1분 이내 확인 결과를 공유해 중복 요청을 줄입니다.
- 인터넷 연결이 복구됐을 때도 다시 확인하며, 연결 오류나 서버의 요청 제한이 있을 때는 재시도 간격을 둡니다.

업데이트 안내
- 새 버전 확인이 끝나면 업데이트 창과 변경 내용을 바로 표시합니다.
- [업데이트 후 다시 시작]을 누르면 설치합니다. 진행 중인 다운로드·변환이 있으면 작업이 끝난 뒤 설치할 수 있습니다.

적용
- 이번 확인 방식은 v1.9.5 설치 후부터 적용됩니다.
- 이전 버전에서 업데이트 창이 보이지 않으면 [프로그램 업데이트 확인]을 누르세요.
- 공식 공유 링크에서도 최신 ClipCatch.exe를 받을 수 있습니다.
