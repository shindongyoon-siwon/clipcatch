ClipCatch v2.0.0

사용할 때만 업데이트 확인
- 정식판의 15분 간격 백그라운드 업데이트 조회를 제거했습니다.
- 프로그램 실행, 화면 열기, 탭으로 돌아오기, 화면의 버튼·키보드 조작을 계기로 확인합니다.
- 마지막 확인 후 1시간 이내에는 같은 결과를 재사용합니다. 프로그램을 다시 열어도 적용됩니다.
- 설정의 [업데이트 확인]은 즉시 수동 확인입니다. 서버가 요청한 대기 시간은 준수합니다.
- 가만히 열어두거나 사용하지 않을 때는 새 버전을 주기적으로 조회하지 않습니다.

마지막 탭 닫으면 자동 종료
- 마지막 ClipCatch 탭을 닫으면 15초 후 프로그램을 종료합니다.
- 새로고침·다시 열기는 종료를 취소합니다. 다른 ClipCatch 탭이 열려 있으면 종료하지 않습니다.
- 다운로드·처리·업로드·업데이트 작업 중이면 완료를 기다린 후 종료합니다.
- 저장하지 않은 화질 개선 항목이 있으면 페이지를 나갈 때 브라우저가 확인합니다. 결과는 종료 전 저장해 주세요.
- [프로그램 종료] 버튼은 유지합니다.

기존 업데이트 안전장치 유지
- 정식 배포처·SHA256·실행파일 식별 검증, 중복 설치 방지, 실제 종료 확인, 백업·복구·재실행 기능은 변경하지 않았습니다.
- 다운로드, 화질 개선, 폴더 열기, 설정·기록·저장 파일은 유지합니다.

검증 범위
- 배포 전 Windows 후보 파일로 실행 중인 1.9.9 교체, 잠긴 백업, 중복 업데이트, 기록·원본 보존, 실제 Chrome 탭 종료·새로고침·재실행 검사를 수행합니다.
- 정식 공개 주소로만 가능한 1.9.9의 실제 업데이트 버튼·새 EXE 실행 경로는 공개 후 별도 검사합니다. 결과는 GitHub Actions 검사 기록에 남습니다.
- 자동검사는 디자인팀 실제 PC 검사와 다릅니다. 모든 PC의 보안 정책·권한·파일 잠금까지 문제 없음을 보장하지 않습니다.

적용
진행 중인 작업을 마치고 필요한 결과를 저장한 뒤, 공식 링크에서 ClipCatch.exe를 받아 한 번 실행하세요. 상단 v2.0.0을 확인하세요. 기존 폴더를 삭제하거나 중간 버전을 순서대로 설치할 필요는 없습니다.
