ClipCatch v1.9.8

폴더창 표시 개선
- 폴더 열기를 누르면 정확한 저장 경로의 탐색기 창을 찾아 기존 창을 우선 활용합니다.
- 최소화된 창은 복원을 요청하고, Windows의 전면 표시 기능을 사용한 뒤 실제 앞에 표시됐는지 확인합니다.
- 앞에 표시된 것이 확인되면 작업표시줄 안내를 표시하지 않습니다. 표시가 거절되거나 확인되지 않은 경우에만 안내와 폴더 경로를 제공합니다.
- 사용자가 다른 창으로 이동하거나 입력을 이어가면 뒤늦게 창을 가로채지 않습니다.
- 탐색기와의 연결은 제한 시간 내에서만 처리하며, 탐색기를 강제 종료하거나 전역 보안·포커스 설정을 변경하지 않습니다. PowerShell에 의존하지 않습니다.
- Windows의 전면 표시 제한 때문에 모든 PC·모든 상황에서 반드시 앞으로 뜨는 것은 보장하지 않습니다.

기존 업데이트 수정 유지
- v1.9.7의 중복 업데이트 방지, 실제 프로세스 종료 확인, 고유 백업·파일 검증·실패 시 원본 보호를 그대로 포함합니다.
- 실제 v1.9.5·v1.9.6·v1.9.7 실행파일에서의 교체, 잠긴 이전 백업, 중복 설치, 기존 파일·기록 보존 검사를 배포 조건에 포함합니다.
- 디자인팀 PC의 특정 실패 원인은 로그 없이 확정하지 않습니다. 외부 파일 잠금·접근 권한·보안 제품 등 모든 환경의 오류가 없어졌다고 보장하지 않습니다.

적용
작업을 마치고 필요한 화질 개선 결과를 저장한 뒤 공식 링크에서 최신 ClipCatch.exe를 한 번만 실행하세요. 상단 v1.9.8 표시를 확인하세요. 기존 파일·다운로드 폴더를 삭제하지 않아도 됩니다.
오류가 계속되면 반복 실행하지 말고 오류 화면과 %LOCALAPPDATA%\ClipCatch\updater.log를 전달해 주세요.

이번 범위에 포함하지 않은 것
동의 기반 자동 업데이트 옵션은 아직 추가하지 않았습니다. 기존 확인·동의 방식과 실행/화면 복귀 및 15분 확인 주기는 유지합니다. 시작프로그램 등록이나 기각된 편의 기능도 추가하지 않았습니다.
