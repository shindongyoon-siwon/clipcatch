ClipCatch v1.9.7

업데이트 파일 교체 오류 수정
- 업데이트가 겹쳐 실행되지 않도록 Windows 파일 잠금으로 교체 작업을 하나만 허용합니다.
- 교체할 설치 경로의 실제 실행 프로세스와 접속 주소를 확인하고, 작업 중에는 중단하지 않습니다. 정상 종료 요청 후 실제 프로세스가 끝났는지 확인합니다.
- 이전 백업 파일을 먼저 삭제하지 않습니다. 새 백업 경로를 사용하고 새 버전 실행 확인 후에만 백업을 정리합니다. 이전 백업이 잠겨 있어도 새 백업을 보존합니다.
- 실행파일을 옮기기 전에 새 파일의 복사와 검증을 완료합니다. 교체 실패와 실행 검증 실패 시 원본 보존 및 복구 절차를 구분합니다.
- 업데이트 중 다시 실행하면 교체 과정에 끼어들지 않도록 막습니다. 기본 연결 주소를 사용할 수 없다고 임의 주소에서 두 번째 운영판을 시작하지 않습니다.
- 모든 교체 실패를 '완전히 종료해 주세요'로 표시하지 않고 실패 단계·실제 Windows 오류·기록 위치를 남깁니다.

디자인팀 적용
1. 진행 중인 작업을 마치고 필요한 화질 개선 결과를 저장합니다. 이미 떠 있는 업데이트 오류창은 확인을 눌러 닫습니다.
2. 공식 공유 링크에서 최신 ClipCatch.exe를 새로 받아 한 번만 실행합니다. 기존 파일·저장 폴더를 먼저 삭제할 필요는 없습니다.
3. 화면 상단의 v1.9.7 표시를 확인합니다. 이후에는 시작 메뉴의 ClipCatch 바로가기를 사용합니다.
4. 여전히 오류가 나오면 반복 실행하지 말고 오류 코드와 %LOCALAPPDATA%\ClipCatch\updater.log를 전달합니다. 보안 설정을 끄거나 관리자 권한을 임의로 사용하지 않습니다.

범위
이번 버전은 업데이트 교체 안정성 수정입니다. 동의 기반 자동 적용 옵션이나 탐색기 전면 표시 보완은 추가하지 않았습니다. 업데이트 확인 주기·기존 다운로드·화질 개선 기능·확장프로그램은 유지합니다.
디자인팀 실제 PC의 실패 원인은 로그 없이 확정하지 않았으며, 자동검사의 재현 사례와 구분합니다.
