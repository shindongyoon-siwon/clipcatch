ClipCatch v1.9.9

폴더 열기 단순화
- 폴더 버튼에서 기존 탐색기 검색·전면 표시 확인·별도 ClipCatch 보조 프로그램을 제거했습니다.
- 확인한 저장 경로를 Windows 탐색기에 직접 전달합니다. 숨김 실행이나 창 검색 결과 대기가 없습니다.
- 실행 요청이 접수되면 불필요한 작업표시줄 안내를 표시하지 않습니다. 실제 창이 열렸다고 단정하는 성공 문구도 표시하지 않습니다.
- 실행 요청 실패 시 오류와 저장 경로를 표시합니다. 항상 맨 앞으로 강제 전환하는 기능은 제공하지 않습니다.

업데이트와 기존 기능
- v1.9.7의 업데이트 중복 방지·실제 종료 확인·검증·백업·복구 코드는 변경하지 않았습니다.
- 기존 이미지 다중 입력·AI 처리·미저장 결과 보호·다운로드·설정·기록은 유지합니다.
- 자동 적용 옵션, 시작프로그램 등록, 기각한 편의 기능은 추가하지 않았습니다.

검증 범위
- 배포 전 Windows에서 실제 Google Chrome 버튼을 눌러 정확한 저장 폴더의 탐색기 창이 나타나는지와 소요 시간을 측정합니다.
- 기존 실행파일 교체, 잠긴 백업과 중복 업데이트, 원본·기록 보존 검사를 유지합니다.
- 공개 후 실제 이전 배포본의 업데이트 버튼 및 새 EXE 직접 실행 경로를 공식 배포 주소로 확인합니다. 결과는 GitHub Actions 검사 기록에 별도로 남깁니다.
- 자동검사는 디자인팀 PC 자체의 검사와 다릅니다. 모든 PC의 보안 정책·파일 잠금까지 문제가 없다고 보장하지 않습니다.

디자인팀 적용
필요한 결과를 저장하고 진행 중인 작업을 마친 뒤, 공식 링크에서 최신 ClipCatch.exe를 새로 받아 한 번만 실행하세요. 상단 v1.9.9 표시를 확인하세요. 중간 버전을 차례대로 설치하거나 기존 저장 폴더를 삭제할 필요는 없습니다.
오류가 계속되면 반복 실행하지 말고 오류 화면과 %LOCALAPPDATA%\ClipCatch\updater.log를 전달해 주세요.
