ClipCatch v1.9.6

화질 개선
- 파일 선택을 브라우저 방식으로 바꿔 기존 파일 선택창이 보이지 않던 문제를 개선했습니다.
- 이미지 여러 장 선택, Ctrl+V 이미지 붙여넣기, 파일 드래그를 지원합니다.
- 이미지별 진행 상태, 취소·재시도, 선택 결과 일괄 저장을 제공합니다.
- 확인한 이미지 초안은 AI를 다시 실행하지 않고 그대로 저장합니다. 영상 초안과 최종 영상 처리는 기존 구분을 유지합니다.
- 같은 설정의 이미지들을 작은 묶음으로 처리해 AI를 반복해서 실행하는 준비 비용을 줄였습니다. 모델·처리 배율·화질 설정은 바꾸지 않았고, 실제 속도 효과는 이미지와 PC에 따라 다릅니다.
- 현재 작업 목록에 남아 있는 미저장 결과를 최근 기록 30개 제한과 별개로 보호합니다. 50장 초안 생성 후 전체 저장과 일부 실패·취소 후 재시도 검사를 포함했습니다.
- 미저장 결과 보호는 실행 중인 프로그램 세션에 한합니다. 종료·재부팅 후 복구 기능은 아니므로 필요한 결과는 종료 전에 저장해 주세요.

실행·종료 및 표시
- 기존 라임색 아이콘을 Windows 실행파일에 적용하고 제품 이름을 ClipCatch로 표시합니다.
- 화면 접속 준비를 확인한 뒤 브라우저를 엽니다. 중복 실행 시 기존 작업 화면을 우선 활용합니다.
- 종료 버튼을 '프로그램 종료'로 명확하게 표시하며, 진행·대기 작업이 있으면 확인합니다. 종료에 실패했는데 완료로 표시하지 않습니다.
- 브라우저 보안 제한으로 기존 탭을 무조건 맨 앞으로 가져오는 동작은 보장하지 않습니다.

유지되는 것
- 실행파일명 ClipCatch.exe, 기존 공유 링크, 설치·저장 위치와 다운로드 기록을 유지합니다.
- 업데이트 확인은 실행·화면 복귀 시와 실행 중 15분 간격으로 유지합니다.
- 시작프로그램 등록, 최초 사용 안내 팝업, 파일 열기·파일 위치 추가 버튼, 저장 폴더 선택 기능은 추가하지 않았습니다.
- DEV196/TEST2 파일·설정·저장 위치를 운영판으로 복사하거나 이전하지 않습니다.

업데이트
운영판에서 '업데이트 후 다시 시작'을 선택하세요. DEV196을 쓰고 있었다면 그 테스트판을 종료하고 공식 ClipCatch.exe를 실행하세요. 기존 테스트판이 운영판으로 자동 변환되지는 않습니다.
확장프로그램 사용자는 프로그램 업데이트 후 chrome://extensions에서 ClipCatch Browser를 새로고침해 주세요.

검증
배포 전 기존 기능 검사, 50장 저장·실패·취소 검사, 브라우저 입력 검사, Windows 운영판 식별·신규 설치·실제 v1.9.5에서의 업데이트·기존 파일 보존 검사를 수행합니다. 자동검사와 사용자 PC의 실제 GPU·클립보드 환경 검증은 구분합니다.
