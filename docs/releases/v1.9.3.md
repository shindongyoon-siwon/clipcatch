ClipCatch v1.9.3

다운로드 오류 수정
- 한글·이모지가 포함된 제목과 파일 경로를 출력 인코딩에 관계없이 읽도록 수정했습니다.
- 웹 화면에서 링크를 입력했을 때 실제 저장 파일을 찾지 못해 CC-421로 표시되던 문제를 수정했습니다.
- 이전 실패 항목을 다시 받을 때 깨진 파일 정보가 남아 새 결과와 섞이지 않도록 했습니다. 기존 파일은 삭제하지 않습니다.

오류 안내
- CC-421을 진단 정보 복사에서도 그대로 표시합니다.
- 파일이 하나여도 파일별 실패 이유를 보여줍니다.
- 완료 파일이 0개일 때 성공 파일이 있다는 식의 안내가 나오지 않도록 정리했습니다.
- 다운로드 단계에서 확인한 실패 이유를 이후 파일 검사 결과가 가리지 않도록 했습니다.

화면 정리
- 상단 운영판 안내와 반복 설명을 정리했습니다.
- 기본 화면은 영상 링크, 저장 방식, 다운로드, 작업 내역 중심으로 구성했습니다.
- 업데이트 확인, 공유 링크, 인증, 진단은 [설정 · 도움말]에서 사용할 수 있습니다.
- 화질 개선, 확장프로그램 연결, 기존 파일 변환 기능은 유지합니다.

적용
- 프로그램의 업데이트 안내에서 [업데이트 후 다시 시작]을 누르세요.
- 업데이트 후 실패한 링크를 다시 입력하거나 [실패한 영상 다시 시도]를 선택하세요.
- 확장프로그램을 사용한다면 Chrome 확장프로그램 관리 화면에서 ClipCatch Browser를 새로고침해 주세요.

검증 범위
- 한글 출력 조건에서 기존 경로 손상을 재현하고 수정 후 경로·영상·음성을 확인했습니다.
- 자동 검사 통과와 디자인팀 PC에서의 실제 사용 성공은 구분합니다. 사용자 PC의 Windows 실행·프리미어 가져오기는 별도 확인이 필요합니다.
